# Get Docker

This script is customized for AcePanel. For general users, we recommend using [LinuxMirrors](https://github.com/SuperManito/LinuxMirrors) to install Docker.

## Usage

```bash
bash get-docker.sh --source mirrors.tencent.com/docker-ce --source-registry docker.1ms.run --protocol https
```
